# Newsletter Playbook v1

## Structures

### Pain → Solution → CTA (`pain_solution_cta`)

- Description: Simple conversion-focused email linking main pain to your product + clear CTA.
- Steps:
  1. State the main pain clearly.
  2. Connect the pain to a real consequence.
  3. Introduce the product as the solution.
  4. Finish with one clear CTA.
- Good for: SaaS, B2B, tools
